pourquoi
ADR-016 · gate de reconnaissance
Aucune migration sans confirmation explicite. L'utilisateur voit chaque espace (titre, type, historique, volume, date) avant de décider.
UC-10 · règles
Migration espace par espace, tout-ou-rien. Une session en cours bloque son espace. La config vue session n'est pas reprise (avertie d'emblée).
S4 · maquette
Sélection par espace (éligibles cochés par défaut ; bloqué non sélectionnable) = choix de maquette, non arbitré par le corpus. Granularité globale : lot unique (décision opérateur 2026-07-09). En cas de rejet : rapport par espace, données locales intactes (E5).
