AR-01 · AR-17
Ossature : Tableau de bord → Espace → {Préparation | Vue session}. L'espace personnel se branche sur Préparation seulement, figure hors quota, jamais bloqué ni grisé.
AR-09 · UC-06 A5
Une session en cours dans un espace partagé se reprend en un clic via le repère « session en cours », sans reconfiguration.
AR-15
Ce tableau est un état de navigation, pas l'écran d'atterrissage de la première ouverture (capture dans l'espace personnel — onboarding capture-first).
S7 · accès compte
L'accès compte est un composant de châssis : même affordance sur toutes les surfaces MJ (y compris vue session et mode local, où elle propose « créer un compte ») — pas seulement ici.
