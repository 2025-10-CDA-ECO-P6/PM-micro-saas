# Parcours bout-en-bout — Index

Les parcours bout-en-bout couturent les use cases du point de vue d'un persona. Ils complètent les User Journeys (UJ), qui restent la source de vérité par use case, par une lecture transverse : le fil narratif propre à chaque persona, les transitions entre UC, et la vérification des coutures inter-UC.

## Relation avec les User Journeys

Les User Journeys (`user-journeys/UJ-UC-*.md`) détaillent les étapes pas à pas par use case. Les parcours ici ne dupliquent pas ce contenu : ils renvoient vers les UJ porteurs et ajoutent le fil transverse — ce qu'un persona traverse du début à la fin, les coutures entre UC, les points de friction.
